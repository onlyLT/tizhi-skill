这套 Skill 怎么用？

  1. 一

    下载解压

    下载 ZIP 解压，保留完整的 tizhi-skill 文件夹（含 SKILL.md 与 references/）。

  2. 二

    放入你所用 agent 的 skills 目录

    凡支持 Agent Skills 规范的 agent 都能装，文件夹名保持 tizhi-skill。常见位置：

    Claude Code

    ~/.claude/skills/tizhi-skill

    Codex

    ~/.codex/skills/tizhi-skill

    Cursor 等其他 agent 参照各自文档的 skills 目录放置；团队共用可放进项目内约定的 skills 目录。

  3. 三

    对话中自然触发

    领导让我"随便写写"一个总结，我真随便写行吗？入职俩月，第一次接这种活。

    重启会话后，聊到体制内处境会按 skill 的触发条件自动生效；多数 agent 也支持按名字点名调用（如 /tizhi-skill 或"用 tizhi-skill 帮我看看…"）。

叁

并非有问必答的百科

它是怎么想事情的？

01
摸

摸底

先问清最影响判断的一两样——单位性质、对方原话、你的位置。信息不够不硬答，不给正确的废话。

02
诊

分诊

把事归入六类情境：领导、同事、办事、自保、晋升、心态。跨类就融成一个回答，不堆两套话术。

03
镜

三层透镜

每条建议过三遍：对方真正想要什么、对你的风险与口碑、具体怎么说怎么做。

04
动

给动作

一句判断，点破潜台词，给能直接照说的成句话术，最后附一条避坑提醒。

交底
缘起

从踩过的坑里，攒出来的一套交底。

体制内的规则，一半写在文件里，另一半靠人踩坑踩出来。这个 Skill 把后一半——那些没人明说、但迟早用得上的门道——整理成了可复用的方法，让 AI 像一个早几年进去的人那样，帮新人看懂局、不吃亏、守住自己。

红线在先：不教违纪违法、不教弄虚作假、不教打压他人。讲隐性规则是为了让人看懂局、保护好自己，不是教人钻空子——涉及这些时它不会配合，只会点破风险、劝回正路。
